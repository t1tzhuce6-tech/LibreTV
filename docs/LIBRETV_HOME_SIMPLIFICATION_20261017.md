# LibreTV 首页简化与旧体系拆除（2026-10-17）

## 目标
按用户截图要求：LibreTV 标志 → 首页搜索 → 历史记录 → 片源库 / 热榜发现。旧 DR 影视入口、方案一/方案二及其背后的运行逻辑彻底从 LibreTV Web 项目删除。

## 本轮修改
- 主页面删除 DR 影视导航和浮动历史入口，搜索下方增加历史记录区；最近搜索保留，观看历史可展开完整记录，继续观看移动到该区。
- 两个卡片的页面路由保留：?view=sources、?view=ranks；导航移到搜索及历史下方，内容再排在导航后。
- 删除整个 DR 独立网页及 js/dr-portal.js、css/dr-portal.css、css/dr-navigation.css；同时移除 PWA 缓存引用，不影响 D:\Services\drpyS 独立 Docker 服务。
- 删除两个配置方案切换管理器 js/profile-manager.js、css/profile-schemes.css、专用 /managed-sources Pages Function 与缓存引用；没有后台定时订阅，不再切换或恢复不同方案的 localStorage 快照。
- 保留注册在 API_SITES 中的直接 CMS 源、自定义 API 和安全过滤。热榜仍可全选、反选、取消勾选、排序，普通搜索不被两种旧方案限制。
- 移除残余 LibreProfiles 的调用和旧 scheme CSS 规则；历史相关处理仍沿用原 UI/体验模块。
- 删除只用于旧 DR/方案功能的过期测试，增补首页简化回归测试，仍保留过滤、分类、搜索、影视榜单等相关测试。

## 验收
- 2026-10-17 本地 node --test：121/121 PASS。
- 本地静音 Chrome：搜索 → 历史 → 入口卡片 → 当前内容 DOM 顺序正确；不存在 DR 链接和方案框；22 个安全源可用，切换正常，全选/反选与保存正常，三级分类层级正确，未发现浏览器 JS 异常。
- 此验收未播放视频，不表示全部影片可播放。
- 本轮仅在 PR #27 开发分支修改；Cloudflare 预览完成前不得称为正式网站上线。

## 特殊边界
- 独立 drpyS Docker 服务不删除、不重装、不改端口或代理。
- 旧管理订阅移除后，自动订阅的来源不再动态同步；可在统一片源管理中手动添加 CMS 源，或另行设计无方案切换的新自动来源机制。
- PR #26 的新增 CMS 源未与本轮合并。
