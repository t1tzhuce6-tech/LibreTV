# 🌟央视大全｜LibreTV 新版统一片源接入（2026-10-19）
## 基线
- 本次从最新已合并的 `origin/main 7e82476` 创建 `feat/cctv-unified-source-20261019`，不复用旧版 PR #29 的页面、DR 或旧片源交互。
- 用户指定：央视仅为新版统一片源库的一个来源；搜索和热榜可选片源共享；名称带🌟。只做视频点播，不碰直播、代理/TUN、DR。
## 实现
- `js/cctv-source.js`：把唯一 `cctv_official` 注册到现有 `API_SITES`，显示名 `🌟央视大全`，并提供安全的央视官网全集选择弹窗。
- `functions/cctv-vod.js`：通过固定央视官方接口动态响应 LibreTV 的 MacCMS 风格契约，包含 `ac=list` 分类、`ac=videolist&t=...` 源目录、`ac=videolist&wd=...` 搜索、`ac=detail&ids=...` 选集。
- 新版 `js/browse-live.js`、片源注册表、`js/rank-source-prefs.js` 无需特别定制央视 UI；通过统一 `API_SITES`、安全源列表自动展示和选择。
- `js/search.js` 对唯一同站 `/cctv-vod` 直连，其他片源原路径不变；首页和播放器页都注册央视源。
- `js/quick-play.js` 可查询央视官方搜索，但央视单集只作为明确的官网链接供用户选择，不伪装成 `.m3u8` 或 MP4 直链。
- `service-worker.js` 版本更新；`/cctv-vod` 网络实时请求，不被离线站点缓存成永久目录。
## 证据与边界
- 2026-10-19 官方央视 API 真实请求：纪录片第一页24部，作品《广济沧海》四集，《今日说法》栏目20条；央视搜索关键词《广济沧海》返回15条视频。
- 单元测试 + 当前项目回归全部通过，包含安全源列表与榜单选择、同站直连、非央视源保持现有代理机制。
- 目前官方央视网页链接是观看入口，不宣称 LibreTV 已能站内高清/4K解密或独立连续播放。央视确实提供分类和视频元数据，但是否能合法稳定获得可直接播放的1080P/4K媒体，仍待单独验证。
- 发布流程：新 PR → GitHub CI → Cloudflare 预览接口和浏览器验收 → 再合并正式 main。不允许从旧版 PR #29 直接回灌。
